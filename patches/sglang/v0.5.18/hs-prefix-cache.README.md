Apply `spec-capture.patch` unchanged to SGLang `71de97b264b04dcd514cf904003028aefe9775c8`, commit that official patch separately, then apply `hs-prefix-cache.patch`. The delta is not a replacement for the official capture patch. Exact hashes and expected final tree are in `hs-prefix-cache.manifest.json`; the recorded replay applied both patches to a fresh local clone and obtained the exact source tree.

Enable reuse with `--enable-spec-capture --spec-feature-cache --enable-deterministic-inference`. Keep the selected capture method/layers, BF16 FA3, page size1, single full prefill and `max_new_tokens=0`. Hybrid targets require `--mamba-radix-cache-strategy extra_buffer`, the actual FULL+MAMBA backend and the selected CUDA Triton FP32 recurrent-state pool. The HS-specific GDN checkpoint stores FP32 state while preserving the ordinary BF16 output math; cache-off retains the upstream path. Unsupported lossy/replay checkpoint modes fail explicitly.

Budgets are independent: `--spec-feature-chunk-tokens`, `--spec-feature-cache-bytes`, `--spec-feature-pinned-bytes`, `--spec-feature-output-bytes`, `--spec-feature-device-bytes`, and `--spec-feature-attempt-capacity`. Defaults are C256, pageable cache1GiB, pinned256MiB, complete output512MiB and retained device snapshots256MiB. Idle pinned arena allocation remains accounted separately from active reservations.

Use the matching SpecForge adapter and Mooncake store identified by the manifest. Protocol-v1 negotiates `published_ownership=attempt-v1`: physical keys include the server epoch and reservation token. A strict PUBLISHED certificate transfers complete gen1 sample objects only after sink readers, the materialized sample and output reservation drain. Normal adopt/get/release/removal then use local ownership and zero server control RPCs. Capability is memoized; begin reservations support batches with per-intent singleflight, so independent Teacher endpoints do not share a network lock. Legacy servers and unresolved writers retain explicit read/cleanup permits or cancellation fences. Unknown capability falls back to isolated full prefill; uncertain old ownership fails closed.

Producer ownership ends when refs may be visible in the durable stream. Successful terminal cleanup requires both joined-producer EOF and successful Consumer drain, and deletes only exact published attempt keys. Failure or timeout does not authorize reclaiming handed-off objects. Delayed callbacks cannot target a later same-sample attempt.

The controller uses four assembly workers by default with disjoint aligned slots in one bounded, retained pinned arena. Slots are reusable only after DMA and CPU suffix reads drain. Ready samples share batched sink publication. After sink drain, the cache may adopt the complete output allocation without a second CPU fill copy; chunk views share that owner. Budgets charge the full unique underlying allocation, including prefix and tail, and group eviction respects every chunk lease. Cache READY is delayed until this ownership transfer. Report actual backing bytes separately from logical chunk bytes, and release-time adoption separately from worker cache-fill timing. Fixed pending-batch limits are bypassed only where controller byte budgets already bound the jobs.
